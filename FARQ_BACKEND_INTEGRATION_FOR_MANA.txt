1. WHAT ROSHAN HAS BUILT (WHATSAPP SIDE)
--------------------------------------------------------------------------------
• Ingestion Engine: Connects directly via WhatsApp mobile WebSockets (Baileys).
  Ingests forwarded Videos (.mp4), Voice Notes (.ogg/.mp3), Images (.jpeg),
  and Text claims. Media is staged in ./media_storage/.
• Privacy & Hashing: Zero raw phone numbers. Phone numbers are hashed using
  HMAC-SHA256 with a secret pepper to produce "user_ref".
• Guided Questions State Machine:
  While backend works, asks 3 questions:
  - Q1 (claims_to_be): official | famous_expert | bank_upi | family_friend | company_boss | not_sure
  - Q2 (asks_for): invest | send_money | otp_link_kyc | nothing_yet
  - Q3 (money_sent): true | false
• 1930 Fast-Path: If user says money_sent=true, the bot IMMEDIATELY interrupts
  with National Cyber Fraud Helpline (1930) and bank account freeze protocol.
• Help Desk: /farq help opens a fraud triage assistant.
• Responsible AI Renderer: Strictly renders LIKELY_SCAM, CONFIRMED_SCAM, or
  NOT_VERIFIED. Zero raw confidence percentages. Displays source diffs.

2. THE 4 ENDPOINTS MANA MUST EXPOSE (FASTAPI)
--------------------------------------------------------------------------------
All requests from Roshan carry header:
X-API-Key: <FARQ_API_KEY>

--- [A] GET /healthz ---
Response (200 OK):
{"status": "ok"}

--- [B] POST /cases ---
Headers:
  X-API-Key: <FARQ_API_KEY>
  Content-Type: multipart/form-data (for media) OR application/json (for text)

Multipart Form Fields (when user sends Video / Audio / Image):
  • file: binary stream of the media
  • media_type: "video" | "audio" | "image"
  • idempotency_key: string (unique case ID e.g. "c_m1a2b3c4...")
  • user_ref: string (HMAC-SHA256 hash of sender phone)
  • caption: string (optional accompanying text)
  • is_forwarded: "true" | "false"
  • frequently_forwarded: "true" | "false" (>5 forwards)
  • language: "en" | "hi"
  • received_at: ISO 8601 UTC timestamp

JSON Payload (when user sends Text claim):
  {
    "media_type": "text",
    "text": "The Finance Minister announced a 40% guaranteed trading scheme.",
    "idempotency_key": "c_m1a2b3c4...",
    "user_ref": "a3efcbb07759f739...",
    "is_forwarded": true,
    "frequently_forwarded": false,
    "language": "en",
    "received_at": "2026-10-24T16:20:00Z"
  }

Expected Backend Response:
• Standard Queue (Celery Worker): Return 202 Accepted:
  {
    "case_id": "c_7f3a8b9c1d2e",
    "status": "queued",
    "eta_seconds": 45
  }
• Known-Fake Cache Match: Return 200 OK with full result schema immediately.

--- [C] PATCH /cases/{case_id}/answers ---
Headers:
  X-API-Key: <FARQ_API_KEY>
  Content-Type: application/json

Body:
  {
    "claims_to_be": "official",
    "asks_for": "invest",
    "money_sent": false
  }

Usage in Mana's Pipeline:
• If claims_to_be = "official": Narrow speech-matcher to verified Sansad TV /
  PIB speech archives (cuts search time from 40s to 3s).
• If money_sent = true: Bump Celery task to High-Priority GPU queue.

Response (200 OK):
{"status": "answers_recorded", "case_id": "c_7f3a8b9c1d2e"}

--- [D] GET /cases/{case_id} (Polling Fallback) ---
Headers:
  X-API-Key: <FARQ_API_KEY>

While processing:
  {"case_id": "c_7f3a...", "status": "processing", "stage": "checking_sources"}

When done: Returns the Section 5.6 Result Schema below.

STRICT RULES:

4. HOW TO CONNECT ROSHAN'S BOT & MANA'S BACKEND
--------------------------------------------------------------------------------
1. Mana runs her FastAPI backend on port 5001:
   uvicorn main:app --host 0.0.0.0 --port 5001 --reload

2. Mana exposes it to the internet with 1 command (zero signup):
   cloudflared tunnel --url http://localhost:5001
   (Cloudflare gives an HTTPS link like https://random-name.trycloudflare.com)

3. Mana sends that link to Roshan. Roshan sets it in farq/.env:
   FARQ_API_BASE_URL="https://random-name.trycloudflare.com"
   FARQ_API_KEY="farq_secret_key_2026"

4. Done! All forwarded media from WhatsApp automatically streams into Mana's
   backend pipeline, and Mana's results reply directly to the WhatsApp user.
